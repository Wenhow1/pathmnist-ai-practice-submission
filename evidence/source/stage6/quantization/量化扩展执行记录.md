# 第六阶段：冻结后量化与离线推理扩展记录

**结论（2026-09-28）：保留 FP32 ONNX 作为可靠离线 CPU 演示模型。**对冻结权重 `D_seed2026` 做的两次静态 8 位后训练量化都显著降低验证集九类分类表现，而且在本服务器 CPU 上比各自同轮 FP32 ONNX 更慢。量化模型、失败结果和独立审计全部保留；这不是对 A—E 正式实验或最终测试结果的修改。

## 全验证集效果与开销

两次均在官方有效验证集 **10,004 张**图像上评估。FP32 ONNX 的 Macro-F1 为 `0.9980726514172686`，与正式冻结权重原验证值完全一致。每次的 FP32/8 位速度均由同一段 ONNX Runtime 代码在同一服务器 CPU 上测试：`CPUExecutionProvider`，单线程，batch=1、零张量，预热 50 次后计时 500 次；**不含**预处理或 session 创建。两轮 FP32 的微小延迟差异反映计时波动，应在每轮内比较。

真实权重的离线单图冒烟验收也已完成：从验证集取一张 128×128 PNG，FP32 ONNX 返回九类概率，总和约 1，预测第 5 类平滑肌与该图真实标签一致；故意损坏的 PNG 被拒绝并给出“无法读取图片”的明确错误。这个单图结果仅验证程序链路，不用于统计性能估计或重新选模。冒烟记录在服务器本扩展目录 `smoke/`，本地只复制预测 JSON/真实标签/错误文本，不复制图片。
