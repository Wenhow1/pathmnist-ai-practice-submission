# 方法与实验协议

研究问题是模型架构和输入分辨率对组织分类效果与计算开销的影响。A 对 B 和 C 对 D 比较分辨率，A 对 C 和 B 对 D 比较模型，D 对 E 比较训练增强。只改变指定因素，其余训练参数一致。

图像使用官方 128px 版本，64px 从同一张图像缩放得到。训练增强包括水平翻转、垂直翻转、90 度整数倍旋转；验证和测试保持确定性。两种模型采用各自的 ImageNet V1 预训练权重，其预训练过程不完全相同，应在讨论架构差异时保留这一限制。

预设主要指标为九类 Macro-F1，辅助报告准确率、宏平均 one-vs-rest AUC、逐类精确率、召回率、F1、灵敏度与特异性。没有正例或负例时，AUC 显式记为不可用，不能填成 0。

在不查看测试表现的前提下，以验证集早停并选择演示模型。三种子的验证均值距最优不超过 0.005 的配置比较 CPU 延迟；最终用该配置验证分数最高的一次权重。

CPU 延迟统一在冻结阶段重新测量，保证同机、同线程设置。输入为 batch=1 的定长张量，预热 50 次后计时 500 次，不含数据读取或预处理。展示界面的耗时包含预处理，二者不可混用。

同一次实验同时保留配置、数据清单标识、代码标识、环境信息、权重和逐图预测。冻结完成后才使用测试集计算最终指标。结果汇总从预测文件重算指标，并检查样本 ID 与完整测试集合一致。

数据包没有患者 ID，官方训练/验证划分不能由本工程证明为患者独立。原始研究的独立外部测试是来源证据，当前程序只核验图像文件与精确重复项。使用三个随机种子检验训练稳定性，不作患者层面统计显著性检验。

实际进度和逐次结果分别记录在各阶段实验笔记中，正式配置以运行生成的 `runs/formal/matrix.json` 为准。最终讨论必须根据运行结果撰写，不能预设提高分辨率必然提高效果，也不能预设轻量模型优于 ResNet。
