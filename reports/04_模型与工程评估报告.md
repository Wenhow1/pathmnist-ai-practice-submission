# 摘要与阅读导航

## 摘要

本项目面向 PathMNIST 九类结直肠病理组织图像块分类，研究模型方案与输入分辨率对分类效果和计算开销的影响。采用官方 128 像素数据及固定训练 / 验证 / 测试划分，设置 ResNet-18 和 MobileNetV3-Small 在 64×64、128×128 输入下的四组主实验，并增加 MobileNetV3-Small／128 关闭整套几何增强的 E 组消融。每组使用三个随机种子，共完成十五条正式训练轨迹。两种网络分别从 ImageNet V1 权重初始化，替换九类输出层并全网络微调。[E02–E10]

在同中心官方验证集上，A—E 的组均 Macro-F1 为 0.995818、0.998599、0.992592、0.997821 和 0.996269。配置及权重锁定后，在另一中心 7,180 张图像上统一评价，组均 Macro-F1 分别为 0.905852、0.909398、0.867163、0.924315 和 0.934814。128 输入相对 64 的测试收益在 ResNet-18 为 +0.003547，在 MobileNetV3-Small 为 +0.057153。128 输入下，D 对 B 的测试 Macro-F1 高 0.014917，参数量约少 86.3%，统一 PyTorch CPU 前向中位延迟的组均值为 1.845 对 12.540 ms。D−E 在验证集为 +0.001552，在测试集为 −0.010498，三个种子的测试差值均为负。[E09–E13]

正式演示模型按测试前的验证分数和 CPU 开销规则固定为 D_seed2026。其测试 Accuracy 为 0.948747、Macro-F1 为 0.929008，但癌相关间质 Recall 仅 0.624703。冻结后的两版八位 PTQ 均严重损失验证精度；第七阶段保留早期五个指定卷积节点为浮点的混合精度候选，将验证 Macro-F1 恢复到 0.995668，文件缩小约 69.9%，但同次 CPU 前向仍慢约 26.2%。因此默认离线演示保持 FP32 ONNX，量化变体作为工程候选保留。[E14–E20]

项目形成数据探索、逐图结果复核、冻结追溯、异常输入处理及 AI 协作记录。结论仅限当前图像块任务、三个训练种子和一个外部中心；NPZ 缺少患者 / 切片标识，尚不能自行核验患者级独立性，也没有开展病理专家或临床验证。

关键词：PathMNIST；病理组织分类；输入分辨率；轻量网络；Macro-F1；训练后量化

# 1  任务定位与研究问题

## 1.1 课程任务与项目边界

课程第一阶段要求选择公开医学或生理数据，以 AI 辅助代码完成识别与预测基线，形成数据集探索笔记、使用日志和评估报告。医学图像条目允许图像分类或分割，并涉及量化后离线推理。本文选择图像分类路线，不将第二阶段的树莓派、ECG 采集、云端汇聚等内容写成 PathMNIST 已完成工作。[E01]

本项目接收 RGB 组织图像块，输出九类分数及组织标签。研究不设计新的神经网络，也不搜索全部模型的性能上限，而是在明确的共同协议下比较两种现成模型方案。图像块类别与患者疾病结局属于不同层次；本项目没有患者随访、切片聚合或临床诊断任务。

## 1.2 三个可由现有实验回答的问题

第一个问题是输入尺寸：在样本、标签和划分相同的条件下，将网络输入由 64×64 提高为 128×128，性能和开销如何变化。第二个问题是轻量化：与 ResNet-18 相比，MobileNetV3-Small 是否能够在当前协议下取得有价值的效果与开销组合。第三个问题是增强：固定几何增强组合在同中心验证与另一中心测试中是否表现一致。[E02]

# 2.1  预处理与数据质量检查

## 输入构造

统一以 128 像素文件作为图像来源；size=64 时，对同一 split/index 的图像进行双线性缩放并开启相应抗锯齿设置。随后转为张量，像素缩放至 0—1，再使用固定 ImageNet 均值 (0.485, 0.456, 0.406) 和标准差 (0.229, 0.224, 0.225) 归一化。这是数值尺度处理，不是病理染色归一化。[E03]

A—D 的训练增强包括随机水平翻转、垂直翻转和 90° 整数倍旋转；E 关闭整套组合。验证与测试均采用确定性处理，不执行随机增强。增强操作在线施加，不意味着新增独立患者或改变原始标签数量。原代码不允许为非训练划分打开增强。[E03]

![图2  各划分内部的类别比例。横轴为比例，而不是原始图像张数。[E03]](../assets/class_distribution.png)

## 完整性与关联样本限制

历史准备流程检查六个图像 / 标签数组、尺寸、通道、标签范围、类别计数与有限数值，并记录数组和索引的 SHA-256。跨集合完全相同像素图像为零，因此没有因完全重复而删除或移动样本。NPZ 不含患者或切片 ID；独立图像索引不等于独立患者来源。相关候选审计见第5章。[E03、E11]

训练与验证类别比例接近，而测试类别构成不同。例如，测试集脂肪占约18.64%，碎屑约4.72%。主评价采用 Macro-F1，并同时展示逐类结果。训练代码仍使用普通交叉熵，没有类别加权或重采样；Macro-F1 作为指标并不会自动平衡训练数据。[E03、E05–E06]

# 3  模型方案与迁移学习

实际实现调用 torchvision 的 resnet18 与 mobilenet_v3_small，并加载各自 IMAGENET1K_V1 预训练权重。ResNet 替换 fc 为 Linear(fc.in_features, 9)，MobileNet 只替换 classifier[-1] 为九类 Linear，保留其上游分类器结构。优化器接收 model.parameters()，因此进行全网络微调，而非仅训练新分类头。[E04–E05]

![图3  两种模型的简化机制图。串联箭头表示前向图像 / 特征流，不是精确逐层拓扑，也不是残差捷径的单独画线。[E04、E21]](../assets/G01_model_architecture.png)

ResNet 路径用残差模块组合主分支与快捷连接；全局平均池化将空间特征汇聚后交给分类层。MobileNet 路径以轻量倒残差、深度卷积和部分模块的通道重标定概括，随后汇聚并输出九类 logits。平均和相加本身不是可学习权重，卷积与线性映射等参数在训练中更新。具体通道宽度和逐层块表未从相应版本第三方源码独立核验，本文不补写未经确认的精确拓扑。[E21]

九分类配置下参数量分别为11,181,129与1,527,081。选定这两种方案用于有限范围的受控比较，没有开展不同ResNet深度筛选、从零训练对照或每种架构独立调参。两份预训练权重的源配方不完全相同，跨模型差异不作纯结构因果归因。[E02、E13]

## 共同设置与随机性

各组固定数据清单、共同训练源码和主要超参数。两种输入均取同一原始图像；指定配对 A/B、C/D 比较尺寸，A/C、B/D 比较模型方案，D/E 比较增强组合。A/D 同时改变模型和尺寸，不能称为单因素比较。相同种子也不保证不同架构的逐图随机增强完全同步；配对描述用于组织训练轨迹差异，不等于消除所有随机性。[E02、E21]

每组三个种子改变训练随机过程，数据划分不变。报告每组均值和样本标准差（ddof=1），并计算同种子的指定配对差值。未先平均多个模型的概率进行集成，也未进行K折轮换。三种子标准差描述当前划分下的训练波动，不是患者、切片或中心重抽样的置信区间。

## 为什么不先筛选所有网络与batch size

本项目以可控、可解释的课程比较为目的。ResNet-18与MobileNet是预先选择的参照方案；batch size通过资源可行性试跑统一确定。没有把小样本试跑成绩用于架构海选，也没有证明这两种网络或128批量是所有候选中的全局最优。共同协议能够限制部分干扰，却不代表每种网络都已充分优化到自身上限。[E08–E10]

## 训练扩展的范围决定

在最终测试开放之前，项目决定保留A—E十五条轨迹，不增加ResNet-50、更多种子、额外颜色增强或200轮训练。理由是原问题已由现有对照覆盖，且验证接近上限，下一步更有信息量的是评价锁定模型在另一中心的表现。独立续训原型属于工程验证，不纳入十五条正式效果比较。[E10、E12]

# 4  训练实现与流程验收

正式训练前，先用144张真实训练图像与72张验证图像进行一轮smoke检查，batch为16。重点是训练、保存、重载与指标一致，而非性能估计。其验证Macro-F1约0.5970，不进入正式主结果。随后在两种模型最大输入128×128下，按128、64、32的候选顺序试跑；128已共同通过合成张量前向、反向与优化器步进，因此不再降低候选。[E08]

| 设置 | 实际取值 | 作用或限定 |
|---|---|---|
| 正式batch / workers | 128 / 4 | 共同可行配置；未进行批量精度搜索 |
| 优化目标 | CrossEntropyLoss | 接收N×9 logits和N个整数标签 |
| 优化器 | AdamW，lr=0.0003 | 更新整个模型的可学习参数 |
| 权重衰减 | 0.0001 | 共同正则化设置 |

# 4.1  指标、最佳权重与测试前选择

## 指标定义

预测类别为九类概率的argmax。Accuracy按全部图像计算正确比例；每类以该类对其余八类计算Precision、Recall、F1、灵敏度和特异性，Macro-F1是九个F1的算术平均。宏OvR AUC先用各类别概率计算九个二分类AUC再平均；类别缺正例或负例时显式记为不可用，不补造分数。[E06]


Precision = TP / (TP + FP)    Recall = TP / (TP + FN)


F1 = 2TP / (2TP + FP + FN)    Macro-F1 = (F1₀ + … + F1₈) / 9


Accuracy = 正确图像数 / 全部图像数    Specificity = TN / (TN + FP)

训练直接优化交叉熵，而不是F1。每轮以验证Macro-F1保存最佳权重，连续八轮未提高则早停。停止后重载best.pt并复算验证指标；因此最终使用的是最佳验证轮次，而不必是最后一轮。[E05]

## 配置选择与冻结

|---|---|---|---|
| A | 0.995818 | 10.640 | 是 |
| B | 0.998599 | 12.546 | 是 |
| C | 0.992592 | 1.678 | 否 |

# 5  高验证分数审计与结果可信度

当B/D验证F1接近1时，项目先审查工程与数据问题，再解释模型能力。历史审计检查训练和验证数组、索引、标签、推理模式、概率列顺序、argmax及指标公式，未发现数组误指、标签错位或指标误算。十二份A—D验证CSV均覆盖10,004个唯一索引，独立脚本的复算与保存指标一致。[E11]

| 检查层次 | 历史结果 | 结论边界 |
|---|---|---|
| 完全像素重复 | 跨集合0对 | 不能检出同切片不同图像块 |
| 哈希初筛 | 9,032个候选对 | 图像对数，不是患者数 |
| 像素阈值筛选 | 849对；涉及91个验证索引 | 是相似候选，未证明同一切片或患者 |

# 8.1  量化诊断、有限干预与边界

第七阶段从原校准清单按类固定取18张训练图像，匹配权重与中间激活。原导出与优化FP32的logits在该诊断样本上最大绝对差为0；S8S8的误差在早期块明显增大。诊断中还发现ORT1.30调试权重助手在uint8相减前没有提升类型，导致回绕；通过显式类型提升、合成算例和真实常量DQ节点核对后纠正。这个助手问题不被解释为实际ONNX推理失效的根因。[E18]

依据训练诊断线索，先登记仅一项候选：保留stem及第一块五个指定Conv为FP32，其余量化因素和576校准样本不变。完整验证Macro-F1为0.995668、Accuracy为0.995802；F1损失0.002405，最大逐类Recall损失0.008380，通过预设0.005/0.02工程门槛。这些门槛不是教师确认的评分或临床安全标准。五节点同时保留有效，也不能定位单层唯一机制。[E18]

# 9  讨论、局限与结论

## 9.1 对结果的解释

分辨率收益在两种网络间明显不同，说明输入尺寸不应只按“越大越好”预设。128输入下D同时降低参数和当前CPU前向开销，并取得更高测试组均F1，但该发现依赖所选预训练权重与共同训练协议，不是轻量架构普遍占优的证据。增强组合在验证与外部测试间的方向反转，提示同中心模型开发与外部泛化之间仍有差距。[E13]

外部下降不是单一机制的证明。数据来源、样本构成和潜在染色 / 采样差异同时变化；项目未开展颜色特征基线、染色扰动或专家复核，不能将观察到的差异解释为网络已经学到或依赖某种病理机制。采用早停也不保证消除跨中心下降。

## 9.2 未覆盖的要求与研究限制

第一，NPZ缺患者和切片标识，随机图像块K折技术上可做，却不能保证来源组隔离。本项目未实施或追加K折，三种子不是三折；课程原文列有交叉验证，但没有教师豁免记录。第二，只有一个外部中心与三个训练种子，不能估计患者 / 中心重新抽样的不确定性。第三，没有全面架构和超参数搜索，也未拆开几何增强操作。[E01–E02、E21–E23]

第四，量化候选通过的是工程精度门槛，不是全INT8或推理加速验收，也没有新外部评价；本项目未追加QAT。第五，实际AI工作流为Codex与历史DeepSeek，并非课程材料指定的Claude Code接入方式，不能虚构使用经历或教师认可。第六，现有Mac离线检查不替代课堂设备、其他系统或临床验收。

## 9.3 结论

本项目完成了PathMNIST固定划分上的十五条正式训练和另一中心统一评价。测试结果显示，128输入的组均F1优于64，但改善幅度依赖模型；MobileNetV3-Small／128在当前协议下取得较好的效果与CPU前向开销组合；固定几何增强的验证优势未在另一中心延续。冻结单模型的间质Recall偏低，进一步说明总体Accuracy必须与逐类指标并列解释。

工程方面，项目保留了数据清单、代码及权重标识、逐图预测、独立复核和失败记录，形成默认FP32离线演示。针对早期节点的有限混合精度PTQ改善了验证精度并缩小文件，但没有获得CPU加速。以上均为图像块级研究与课程工程实践成果，不构成患者诊断或临床有效性结论。
