# PathMNIST 项目第一阶段：数据探索与环境核验

日期：2026 年 9 月 23 日  
研究任务：以九类结直肠病理图像块为对象，比较 ResNet-18 与 MobileNetV3-Small 在 64×64、128×128 输入下的分类效果和计算开销。**本阶段只核验数据与运行环境，没有训练正式模型；下文不含分类性能结论。**

## 已准备的数据

项目使用 MedMNIST 的官方 `pathmnist_128.npz`。文件仅存于服务器 `/home/wenhao/pathmnist_course/data`，本地交付包包含审计记录和图表，不包含 4.26 GB 原始数据。文件 MD5 `ac42d08fb904d92c244187169d1fd1d9` 与[官方数据定义](https://github.com/MedMNIST/MedMNIST/blob/main/medmnist/info.py)和 [Zenodo 发布记录](https://zenodo.org/records/10519652)一致。128 像素版本保留 MedMNIST 的划分与样本索引，64 像素实验会从同一批 128 像素图像缩小生成，避免样本差异干扰分辨率比较；依据见 [MedMNIST+ 说明](https://github.com/MedMNIST/MedMNIST/blob/main/on_medmnist_plus.md)。

数据集保留官方训练、验证、测试三份划分：训练 89,996 张、验证 10,004 张、测试 7,180 张，合计 107,180 张。图像数组为 128×128、RGB 三通道、`uint8`；标签为整数 0—8。每个划分的样本数和类别顺序写入 [`manifest.json`](manifest.json)。清单标识为 `ce844e66f5f346beccf155173d3de7ed7b161412f65dc6f5d67a347f2b40590b`，可用于后续实验核对数据是否改变。

## 质量核验及边界

1. 官方 NPZ 的完整文件 MD5 已通过；六个图像／标签数组、各集合索引另有 SHA-256 记录在清单中，重新运行数据核验也通过。
2. 对训练、验证、测试的每张图像计算精确像素哈希，跨集合完全重复数为 **0**。[重复项清单](cross_split_duplicates.csv)为空，因此**没有删除或移动样本**，当前仍是官方原始划分。精确哈希不能检出近似重复或同一切片的不同图像块。
3. 数据准备流程检查了图像尺寸、通道、标签范围和类别数量；从三个集合分别以 64、128 像素配置抽样读取，输出张量的尺寸、标签和数值有限性均通过。随机增强只配置给训练流程，当前没有执行训练。
4. NPZ **不含患者或切片 ID**。来源论文报告了不同患者的外部测试证据，但本项目不能凭当前文件自行证明全部训练／验证／测试样本按患者隔离，更不能把图像块数量当成患者数量。证据分层及报告建议用语见[数据来源与患者独立性](../docs/数据来源与患者独立性.md)。

本项目预测的是**图像块的组织类别**，不能据此宣称对患者癌症进行诊断或预测生存。

## 环境与复现位置

服务器项目目录为 `/home/wenhao/pathmnist_course`，只使用用户自己的 `/home/wenhao` 空间；数据位于其 `data/`，探索输出位于其 `artifacts/`。独立 Python 环境位于该项目的 `.venv/`，没有修改另一个项目 `/home/wenhao/neurostorm_2d` 的环境。两项目共用服务器硬件，因此正式训练时仍需留意 GPU 占用。

实际运行版本：Python 3.12.14、PyTorch 2.14.0+cu130、torchvision 0.29.0+cu130、MedMNIST 3.0.2、NumPy 2.5.2、scikit-learn 1.9.1、Streamlit 1.64.0。完整环境快照见 [`requirements-gpu.lock.txt`](../requirements-gpu.lock.txt)。服务器实际识别两张 RTX 5090，每张约 31.36 GiB 显存；CUDA 小计算通过。项目源码范围的静态检查及 28 项自动测试通过。这些测试检验工程流程，不代表真实数据的模型性能。

在服务器项目目录中复核第一阶段的入口如下；它们不会启动 15 次正式训练：

```bash
.venv/bin/python -m pathmnist_project.cli doctor
.venv/bin/python -m pathmnist_project.cli prepare --data data
.venv/bin/python -m pathmnist_project.cli explore --data data --output artifacts
```

下一阶段按既定计划先以真实数据做小样本训练与保存／重载检查，再试跑 ResNet-18／64 基线。此后才确定统一 batch size，按预先固定的配置开展模型与分辨率对照。正式训练的 ImageNet 预训练权重和测试集分类指标尚未产生。
