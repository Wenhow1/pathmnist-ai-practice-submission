# PathMNIST 数据来源与患者独立性核对

## 本项目使用的数据

使用 MedMNIST 发布的 PathMNIST 128×128 RGB 版本。官方文件为 `pathmnist_128.npz`，MD5 为 `ac42d08fb904d92c244187169d1fd1d9`。训练、验证、测试集分别有 89,996、10,004、7,180 个图像块，标签为 0—8 的九种组织类别。128 像素版本由更高分辨率图像缩小，保留 MedMNIST 的样本索引与划分。预测对象是**病理图像块的组织类别**，不是患者是否患癌。

官方依据：[MedMNIST 数据定义](https://github.com/MedMNIST/MedMNIST/blob/main/medmnist/info.py)、[MedMNIST+ 说明](https://github.com/MedMNIST/MedMNIST/blob/main/on_medmnist_plus.md)、[Zenodo 数据记录](https://zenodo.org/records/10519652)。

## 来源论文与当前数据包分别能证明什么

[来源论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6345440/)描述：训练图像块来自 NCT 和 UMM 的病理切片，外部测试图像块来自 DACHS 研究相关的病理切片；论文称外部测试图像来自与训练数据不同的患者。MedMNIST 将其描述为来自另一临床中心的测试集。这是**来源研究报告的证据**，应按原文引用。

[MedMNIST 发布包格式](https://github.com/MedMNIST/MedMNIST/blob/main/README.md)只有 `train/val/test` 的图像与标签六个数组，没有患者或切片标识。因此本项目可以核对图像模式、标签、类别数量和跨集合的**完全相同像素**，不能仅凭当前 NPZ 自行核验患者级隔离。官方训练／验证划分来自约 100,000 个开发图像块的 9:1 划分；没有患者标识时，也不能断言这两个集合按患者独立。

来源论文自身的内部 70/15/15 实验划分与 MedMNIST 发布包的训练／验证划分不同，不应混为同一次划分。论文所列来源机构和生物样本库之间有联系，也不宜进一步写成“所有测试病例都来自与训练完全无关的机构”。

## 本项目报告用语

- 可以写：来源论文报告了不同患者的外部测试数据；本项目保留 MedMNIST 官方划分，并检查图像块跨集合的完全重复。
- 不能写：本项目独立验证了所有训练、验证、测试患者互不重叠。
- 三个随机种子的标准差反映训练波动，不代表患者层面的置信区间。
